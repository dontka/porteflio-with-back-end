# 🎯 Portfolio Web avec Système de Commentaires - Instructions Copilot

Vous êtes un assistant expert pour ce projet de portfolio PHP/MySQL avec système de commentaires interactif.

## 📋 Vue d'ensemble du projet

**Nom:** Porteflio Donatien KANANE  
**Type:** Portfolio professionnel avec blog interactif et système de commentaires  
**Tech Stack:** PHP 8.3, MySQL, MVC Custom, Bootstrap 5, jQuery, Font Awesome  
**Environnement:** Laragon (localhost) + InfinityFree (production)

## 🏗️ Architecture

### Frontend
- **Framework CSS:** Bootstrap 5 + Tailwind-like custom CSS
- **Interactivité:** jQuery + Vanilla JS
- **Dark mode:** localStorage-based avec synchronisation
- **Responsive:** Mobile-first design

### Backend
- **Framework:** MVC Custom (PSR-4 namespaces)
- **Router:** Pattern matching avec réwriting mod_rewrite
- **ORM:** PDO direct (pas de framework ORM)
- **Structure:**
  ```
  app/
  ├── Core/          # Router, BaseController, View
  ├── Controllers/   # LoginController, RegisterController, APIController, etc.
  ├── Models/        # Requêtes BD
  └── Views/         # Templates PHP
  includes/          # Database.php, functions.php
  ```

### Base de données (MySQL)
```sql
- users (id, username, email, password)
- profiles (id, user_id, github_username, bio, etc.)
- projects (id, title, slug, description, image_url, etc.)
- blog_posts (id, title, slug, content, etc.)
- comments (id, project_id, user_id, content, created_at)
- comment_likes (id, comment_id, user_id)
- skills, experience, education, categories
```

## 🔄 Flux principal

1. **Requête** → `.htaccess` reroute vers `index.php`
2. **index.php** → `Router` parse l'URL
3. **Router** → Trouve le contrôleur/action
4. **Controller** → Récupère données + rend vue
5. **View** → Affiche le template

## ✨ Fonctionnalités principales

### 1. **Authentification**
- Formulaires login/register
- Bcrypt + migration SHA-1
- Session PHP + tokens CSRF
- Routes: `/login`, `/register`, `/logout`

### 2. **Système de commentaires**
- Créer, modifier, supprimer commentaires
- Likes/unlikes sur commentaires
- AJAX-based POST vers `/api?action=X`
- Validation côté server

### 3. **Dark Mode**
- Basé localStorage (`darkMode: 'disabled'`)
- Classe CSS `body.dark-mode`
- Checkbox dans navbar synchronisé
- Persist au rechargement

### 4. **Pages principales**
- **/** : Homepage avec hero, stats, skills, projects, blog
- **/projet/{slug}** : Détail projet avec commentaires
- **/blog/{slug}** : Article blog avec commentaires
- **/api** : Endpoint JSON pour commentaires/likes

### 5. **GitHub Integration**
- Stats images (github-readme-stats.vercel.app)
- Activity feed (gitlab-activity plugin)
- Graphique contributions (github-activity-graph)

## 🐛 Problèmes résolus récemment

| Problème | Solution |
|----------|----------|
| jQuery undefined | Déplacé jQuery en `<head>` |
| Login/Register 404 | Fixed `.htaccess` RewriteBase |
| Commentaires ne marcent pas | Fixed AJAX URLs: `api.php?action=X` → `api?action=X` |
| GitHub Calendar crash | Désactivé plugin bugué, gardé stats images |
| Header/Footer sur login | Changé `render()` → `renderPartial()` |
